# md2docx-cn —— 中文论文 Markdown → Word 生成器

两个脚本，都跑出过真实投稿稿与学位稿：一个按中文期刊投稿模板排版，一个按通用硕士学位论文版式排版。
同一份 Markdown 进去，出来的是能直接交的 `.docx`（三线表、原生公式、原生脚注、自动目录）。

不是通用 Markdown 转换器。它只做一件事：把已经写好、只需排版的论文 md 排成中文期刊/学位论文的样子。

## 环境

Python 3.10+：

```bash
pip install python-docx latex2mathml mathml2omml
```

`docx_to_pdf.py` 另需 `pywin32`（走本机 Word 的 COM 接口导出 PDF，只在 Windows 上有）。

两个生成器本身只依赖前三个包。

## 1. `md_to_docx_journal.py` —— 中文期刊投稿版

```bash
python md_to_docx_journal.py <源.md> <输出.docx>
```

两个参数都必须给；漏给会打印用法并以退出码 2 结束。

### 版式

按中文经管类期刊的投稿模板标定：

- A4；上下 2.54 cm、左右 3.18 cm；单倍行距、段前段后 0
- 主标题小二黑体加粗居中，副标题四号宋体，作者小四黑体右对齐
- 摘要五号楷体；正文五号宋体；一级标题四号黑体；二级标题五号楷体
- 首行缩进 2 字；三线表；表题在上、图题在下
- 参考文献 `[1]` 顺序编码、小五号
- 公式用 Word 原生 OMML（不是 MathType），独立公式左缩四字、右侧连续编号

### 源文件指令

用 `[[TAG]] 内容` 写版面指令，每条独占一行：

| 指令 | 作用 |
|---|---|
| `[[TITLE]] 标题` | 主标题（小二黑体居中） |
| `[[SUBTITLE]] ——副标题` | 副标题（四号宋体） |
| `[[AUTHORS]] 作者` | 作者行（小四黑体右对齐） |
| `[[ABSTRACT]] 摘要全文` | 摘要段（五号楷体，首行缩进） |
| `[[KEYWORDS]] a；b；c` | 关键词行，自动加 `[关键词]` 前缀 |
| `[[CLC]] [中图分类号]F832.51　[文献标识码]A` | 分类号行 |
| `[[DOI]] DOI：` | DOI 行 |
| `[[AUTHORINFO]] 作者简介…` | 作者简介段（五号楷体） |
| `[[PAGEBREAK]]` | 强制分页 |

正文用 `# ` 一级标题、`## ` 二级标题（层级会排出来，编号要在 md 里自己写）。
`# 参考文献` 是特殊标题：从这里开始进入参考文献模式，后续 `[1]` 开头的行按条目排版。

其他识别规则：

- `**表 1　标题**` / `**图 1　标题**` → 题注（表上、图下）。表/图与编号之间有没有空格都认，输出统一成「表1　　标题」
- `**Panel A …**` → 表面板标签
- `脚注：…` → 挂到上一个题注段落末尾，转成 Word 原生脚注（期刊要求的「资料来源」写法）
- `注：…` / `资料来源：…` → 表注/图注（图注下的「资料来源」居中）
- `|…|` 表格块 → 三线表，自动算列宽、按内容自动缩字号；列宽按版心 14.64 cm 铺满
- `$…$` 行内公式；`$$…$$` 独立公式（自动编号）
- `![alt](相对路径)` → 图，路径**相对 md 所在目录**解析；找不到时报警并继续，退出码仍为 0
- `- 列表项` → 悬挂缩进的项目符号
- `*斜体*` / `**粗体**` → 行内强调
- `### 三级标题` → 三级标题（五号楷体加粗，缩进同二级）
- `> 引用` → 小字号缩进段；`1. …` → 悬挂缩进的有序条目；`---` → 分隔线（跳过）

标题都是普通段落（为了精确控字号字体），但三个层级都写了 `w:outlineLvl`，
所以 Word 导航窗格、后续插目录都能认出层级——**外观不变**。

## 2. `md_to_docx_thesis.py` —— 学位论文通用版

```bash
python md_to_docx_thesis.py <源.md> <输出.docx>
```

两个参数都必须给；漏给会打印用法并以退出码 2 结束。

### 版式

通用硕士论文版式（不是任何学校模板）：A4、上下 2.54 / 左右 2.8 cm、正文 12 磅宋体、
一级标题 16 磅居中、二级标题 14 磅、表注 9 磅、三线表。章节标题用 Word 原生 Heading 样式，能生成自动目录。

### 必须知道：它和期刊版用两套不同的头部语法

**学位版没有 `[[TITLE]]` 这一类封面对令。** 它按「位置」认结构：

| md 里的位置 | 被当作 |
|---|---|
| 第一个 `# ` | 论文题目（18 磅黑体居中，**不是** Heading） |
| 第一个 `## ` | 副标题（14 磅居中，**不是** Heading） |
| 之后每个 `# ` | 一级章标题（Heading 1，自动分页） |
| 之后每个 `## ` | 二级节标题（Heading 2） |

所以：

- 学位版的 md **必须以 `# 论文题目` 开头**，再写 `## 副标题`（没有副标题也要留一行 `## `，否则第一个真章节会被当副标题吃掉）
- 如果把期刊版的 `[[TITLE]] 标题` 原样丢给学位版，这些行会**按普通正文排出来**，`[[TITLE]]` 字样直接进稿子
- 第一个 `# ` 之前的任何封面对令都不会被识别

这条踩过一次：用期刊版语法写的 md 跑学位版，题目和副标题变成普通段落、目录只剩「参考文献」一条，
因为除了第一个 `# ` 和 `## ` 之外，只有 `###` 与后续 `#` 才会被放进 Heading 样式。

### 与期刊版的差别

- `[[TOC]]` → 插入两级自动目录（TOC 域）。保存时写 `w:updateFields`，Word 打开会提示更新页码（点「是」）
- 图片宽度固定 6 英寸、居中；路径同样相对 md 目录
- 参考文献无编号（由编辑部/学校统一加），`in_refs` 状态下所有非空行都按条目排
- 支持 `注：` 段落与注释条目
- 公式用 OMML，失败时回落到 Unicode 近似

### 独立公式必须写成多行

期刊版单行 `$$E=mc^2$$` 能认；学位版不认单行，会把它降级成行内公式、并且漏掉一个 `$`
（渲染出来是 `$β̂ = …$`，那个多出来的 `$` 会印在稿子上）。多行式两版都能认：

```markdown
$$
\hat{\beta} = (X'X)^{-1}X'y
$$
```

写完转 PDF 前先跑一次，搜 docx 里有没有残留 `$`——有就是这条没写对。

### 图片路径这个坑（踩过两次）

两个版本都按**源 md 文件所在目录**解析图片相对路径（`SRC.parent / ...`）。
早期版本按固定 drafts 目录解析，结果在 `drafts/` 下写 `output/figures/x.png` 时静默跳过、图不进稿，
而且不报错——因为代码里是 `if img.exists():` 才插入。

现在两版都会在跳过时立刻打印到 stderr：

```
[WARN] 图未找到，已跳过：figs/x.png  (解析为 D:\...\figs\x.png)
[WARN] 1 张图未插入（路径不存在）：
       figs/x.png
```

**看 stderr，不要只看退出码是不是 0。** 也先查路径相对谁，不要查图片本身。

## 3. `docx_to_pdf.py` —— 导出 PDF 预览

```bash
python docx_to_pdf.py <输入.docx> <输出.pdf>
```

用本机 Word 的 COM 接口导出（`ExportFormat=17`），期间 `Fields.Update()` 更新域（目录页码），
`DisplayAlerts=0` 是为了不弹「更新域」确认框卡住。页数打印到 stdout。

限制：OMML 公式导出正常；如果正文里漏了没渲染的 LaTeX 源码，PDF 里会原样显示。

## 4. 实测规模

用真实稿件跑过（数字由 `docx_to_pdf.py` 的 `pages:` 行给出）：

| | 期刊版 | 学位版 |
|---|---|---|
| 源 md | 1.2 万汉字 | 3.2 万汉字 |
| 产出 | 13 页、9 表 1 图、25 条参考文献 | 58 页、13 表 4 图、46 条参考文献 |
| 一次生成耗时 | 约 2 秒 | 约 3 秒 |

不含 Word 打开后的分页与题注挤压二次调整。

## 5. 这些脚本不做什么

- **不做内容检查**：数字对不对、引用全不全、表号连不连续，全在稿子本身
- **不做学校模板套用**：学位版是通用版式。学校模板到位后，封面、页眉页脚、致谢、字体字号要手改或另写
- **不做查重**
- **不做图表生成**：图是外部生成好的 PNG，脚本只负责插进版式

## 6. 最小示例

`examples/` 下有两份可直接跑的 md（`journal_demo.md` 用期刊版语法、`thesis_demo.md` 用学位版结构），
`examples/figs/trend.png` 是示例图。

```bash
python md_to_docx_journal.py examples/journal_demo.md out_journal.docx
python md_to_docx_thesis.py  examples/thesis_demo.md  out_thesis.docx
```
